Third-party notices for includes/cli-router/

What this directory takes from WP-CLI, and under which license:

- Code. A file whose header names a wp-cli package as its source ports code
  from that package: wp-cli/wp-cli itself, php-cli-tools, Spyc, or one of the
  command packages below (entity-command, extension-command, role-command,
  super-admin-command, checksum-command, cache-command, cron-command,
  core-command, db-command, embed-command, language-command, media-command,
  rewrite-command, maintenance-mode-command, search-replace-command,
  widget-command).
- Text. catalog/ is generated by bin/wp-cli-catalog.php from the WP-CLI 2.12.0
  phar, so it holds the synopses and help text of every bundled command
  package, those the router refuses included.

Versions are the ones WP-CLI 2.12.0 bundles (vendor/composer/installed.php
inside wp-cli-2.12.0.phar, sha512 be928f6b…), except php-cli-tools: the port
in class-tabular.php states 0.12.6, while the 2.12.0 phar bundles 0.12.5;
both versions carry the same LICENSE text. Each package is distributed under
the MIT license; each notice below is copied verbatim from the package's
LICENSE (Spyc: COPYING) at the stated version, read from the package's
repository at that tag (2026-10-05).

One more source is not MIT: handlers/class-db-handler.php reproduces what
MariaDB's mysqlcheck client prints (GPL-2.0); its attribution is the last
section of this file.
